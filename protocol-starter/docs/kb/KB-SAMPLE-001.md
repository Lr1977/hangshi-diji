# KB-SAMPLE-001: Cantonese prompt-language rule

## Type

- design rule
- experiment conclusion

## Statement

- Cantonese generation is more stable when the prompt uses a Cantonese-specific style pack, short section labels, and explicit anti-Mandarin constraints.

## Why This Matters

- Without a stable Cantonese rule, the model may drift into Mandarin phrasing or lose phonetic control.

## Applies To

- `REQ-SAMPLE-001`

## Does Not Automatically Apply To

- non-Cantonese languages
- unrelated projects

## Evidence

- repeated test runs in the multilingual song project
