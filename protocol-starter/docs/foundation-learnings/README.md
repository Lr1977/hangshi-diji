# Foundation-Learnings

## Purpose

Store experiments, pitfall records, trial outcomes, and experience converted into reusable guidance.

This layer can inform implementation, but it does not automatically become a hard rule.

## Allowed Content

- experiment notes
- pitfall logs
- upstream behavior observations
- prompt strategy outcomes
- repeatability findings

## Required Labels

Each entry should state:

- scope
- verification status
- whether it is promoted into project or core rules

## Read Priority

Read only when a requirement point explicitly binds to it, or when investigating repeated failure.
