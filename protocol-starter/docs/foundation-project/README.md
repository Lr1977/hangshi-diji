# Foundation-Project

## Purpose

Store project-specific requirement structure and project-bound knowledge.

This layer is isolated per project and must not be treated as globally reusable by default.

## Allowed Content

- project requirement docs
- project KB index and entries
- project-specific constraints
- project-specific capability boundaries
- project-specific implementation notes

## Not Allowed

- cross-project generic protocol rules
- loose experiments without project binding
- deprecated material mixed with active project guidance

## Read Priority

Read this after Foundation-Core.
