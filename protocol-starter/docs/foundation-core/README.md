# Foundation-Core

## Purpose

Store only cross-project, stable protocol rules.

This layer is reusable across projects.

## Allowed Content

- plan-before-implement rules
- verification-before-claim rules
- requirement-to-knowledge binding rules
- audit separation rules
- evidence and status labeling rules

## Not Allowed

- project-specific API constraints
- repo-specific paths or ports
- one-off experiments
- temporary debugging notes
- deprecated strategies

## Read Priority

This layer should be read first.
