# GitHub Repository Setup Guide

## 1. Topics

Go to the repository page, then:

1. click `About` on the right side of the repo header
2. click the gear icon or `Edit details`
3. add topics:
   - `ai-agent`
   - `agent-workflow`
   - `requirements-management`
   - `knowledge-base`
   - `developer-workflow`
   - `prompt-engineering`
   - `openai`
   - `codex`

## 2. Social Preview

Go to:

`Settings -> General -> Social preview`

Upload a dark, high-contrast image with:

- title: `Hangshi Diji`
- subtitle: `Keep AI projects aligned across requirements, knowledge, implementation, and verification`

## 3. Pin To Profile

Go to your GitHub profile page, then:

1. click `Customize your pins`
2. select `hangshi-diji`
3. save the profile

## 4. Community Profile

For the repository itself, keep these files current:

- `README.md`
- `LICENSE`
- `CONTRIBUTING.md`
- `CHANGELOG.md`

## 5. What To Keep Visible

The first screen should always show:

- what the project is
- what problem it solves
- what structure it uses
- how to start
- where to learn more

## 6. What Not To Put First

Do not lead with:

- internal implementation details
- private workflow state
- long background stories
- raw chat history
