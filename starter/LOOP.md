# Project LOOP

## Purpose

This project uses a lightweight loop:

1. restore
2. frame
3. plan
4. implement
5. verify
6. audit
7. update docs
8. hand off with evidence

## Restore

Read:

1. `AGENTS.md`
2. `LOOP.md`
3. `STATE.md`
4. `docs/handoff/LATEST.md`

If requirements exist, also read:

5. relevant requirement doc
6. linked `KB-*` entries

## Frame

Before editing, state:

- target outcome
- intended file scope
- verification to run

## Verify

Use project-appropriate checks.

Examples:

- parse or syntax checks
- build
- tests
- browser verification
- auth or request-flow checks

## Audit

Record:

- what changed
- what was verified
- what remains risky
- what still needs human testing

## Hand Off

Update `docs/handoff/LATEST.md` with the session title, what changed, what was verified, and what the next session should read first.
