# Codex Universal Inheritance Kit

> Created: 2026-06-20
> Purpose: give another Codex instance a reusable, project-agnostic working layer that inherits the current operating model, skill usage discipline, lightweight loop, and requirement-to-knowledge binding method

## What This Kit Is

This kit is a portable operating layer for Codex on Windows.

It is meant to transfer not only configuration ideas, but also the working method that has now proven useful across repeated sessions:

1. explicit skill-first behavior
2. plan -> implement -> verify -> audit -> report
3. project-carried context instead of chat-memory-only continuation
4. requirements bound to reusable knowledge entries
5. narrow changes with explicit verification

## What This Kit Does Not Try To Migrate

This kit does not include:

- login state
- secret tokens
- `.env` files
- session history
- local attachments
- raw project runtime state

It is an inheritance layer, not a secret or machine-state clone.

## Recommended Use

Use this kit when:

- moving Codex habits to another Windows machine
- starting a new project that needs stronger continuity
- letting another AI continue work without relying on chat history
- preventing drift between requirement docs, implementation, and past conclusions

## Package Structure

- `MANUAL.md`
- `CAPABILITIES.md`
- `ADOPTION-STEPS.md`
- `starter/`
- `manifest/`

## Core Rule

Do not tell the next Codex to "remember how we work".

Give it a structure that makes the work discoverable:

1. global rules
2. project rules
3. loop
4. live state
5. requirement docs
6. KB docs
7. plans
8. audit evidence
