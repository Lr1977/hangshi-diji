# Naming

## Current Preferred Name

The preferred working name for the requirement-to-knowledge foundation method is:

- `夯实地基`

## Codex Skill Name

For Codex skill naming compatibility, the installed skill name should use ASCII:

- `hangshi-diji`

## Historical Name

Earlier documents may still refer to:

- `requirements-knowledge-binding`

Treat that as the earlier English label for the same core method.

## Why The New Name Matters

`夯实地基` better reflects the actual role of the method:

- not just binding requirements
- but building a stable foundation for later expansion

That expansion can later support:

- richer knowledge structures
- graphs
- maps
- even more structured representations such as 3D or model-like layers if the project needs them
