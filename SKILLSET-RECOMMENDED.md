# Recommended Skillset

## Core Skills To Keep

These are the most important general-purpose skills behind the current working model:

1. `using-superpowers`
2. `lightweight-loop`
3. `hangshi-diji` (`夯实地基`)
4. `writing-plans`
5. `verification-before-completion`
6. `systematic-debugging`
7. `test-driven-development`
8. `writing-skills`

## What Each One Contributes

### `using-superpowers`

- forces skill-first behavior
- reduces process drift at session start

### `lightweight-loop`

- gives the base plan -> implement -> verify -> audit structure

### `hangshi-diji` (`夯实地基`)

- binds project requirements to explicit reusable knowledge
- prevents future continuation from relying on chat memory only
- provides the foundation layer for future knowledge expansion such as graphs or richer structured models

### `writing-plans`

- improves multi-step implementation framing

### `verification-before-completion`

- prevents premature success claims

### `systematic-debugging`

- helps avoid shallow bug-fix loops

### `test-driven-development`

- increases discipline when implementation risk is high

### `writing-skills`

- helps codify newly proven methods into reusable skills or operating guidance

## Optional Skills

Add these only when the project actually needs them:

- `using-git-worktrees`
- `requesting-code-review`
- `receiving-code-review`
- `subagent-driven-development`
- `browser-automation`

## Rule

Do not copy every available skill just because it exists.

Copy the smallest skillset that preserves the working method you actually want.
